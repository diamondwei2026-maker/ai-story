# AI 小说创作平台 — UI 设计文档

> **文档角色**：资深 UI 设计师  
> **撰写日期**：2026-06-12  
> **设计系统**：基于 Ant Design Vue 的暗色文学风设计体系

---

## 一、设计理念

### 1.1 设计定位

本平台面向文学创作者，设计需要在"专业工具感"与"创作氛围感"之间取得平衡。整体采用**沉稳、克制的文学美学**，通过低饱和度的主色调、宽松的排版节奏和细腻的微交互，营造沉浸式的创作环境。

### 1.2 核心设计原则

1. **沉浸优先**：减少视觉干扰，让用户注意力集中在文字内容
2. **渐进引导**：五阶段工作流通过步骤条可视化，让用户始终感知创作进度
3. **内容为王**：大量文字内容的排版必须舒适、可读
4. **操作明确**：在复杂的 AI 工具中，每个按钮和状态都清晰可辨

## 三、字体与排版

### 3.1 字体栈

```
'Inter', 'Noto Sans SC', -apple-system, BlinkMacSystemFont, sans-serif
```

- 西文使用 Inter（现代几何无衬线）
- 中文使用 Noto Sans SC（思源黑体，阅读舒适）
- 系统字体兜底

### 3.2 字号层级

| 层级 | 字号 | 用途 |
|------|------|------|
| H1 | 28px | 页面大标题 |
| H2 | 24px | 区域标题 |
| H3 | 18px | 卡片标题/子标题 |
| XL | 20px | 重点文本 |
| LG | 16px | 次级标题、引导文案 |
| 正文 | 14px | 默认正文、列表项 |
| 辅助 | 13px | 元信息、标签、提示 |
| 小字 | 12px | 脚注、技术信息 |

### 3.3 行高与间距

| 属性 | 值 | 说明 |
|------|------|------|
| 正文行高 | 1.7 | 长文舒适阅读 |
| 大字行高 | 1.8 | 标题/重点文本 |
| 紧凑行高 | 1.5 | 紧凑场景（表格等） |
| LG 间距 | 24px | 区域分隔 |
| XL 间距 | 32px | 大区块分隔 |
| XS 间距 | 8px | 紧密元素间距 |

### 3.4 圆角

| 层级 | 值 | 用途 |
|------|------|------|
| LG | 8px | 卡片、面板、模态框 |
| 默认 | 6px | 按钮、输入框 |
| SM | 4px | 标签、角标 |

## 四、布局系统

### 4.1 页面整体结构

```
┌──────────────────────────────────────┐
│  顶部导航栏 (page-header)              │
│  - 项目标题                            │
│  - 阶段标签 + 模型状态徽章              │
├──────────────────────────────────────┤
│  工作流步骤条 (WorkflowStepper)         │
│  [灵感] → [设定] → [大纲] → [细纲] → [正文] │
├──────────────────────────────────────┤
│                                      │
│  内容区域                             │
│  - 白色背景卡片                        │
│  - 内边距 32px                        │
│  - 圆角 8px                           │
│  - 浅阴影                             │
│                                      │
└──────────────────────────────────────┘
```

### 4.2 项目中心（Hub）

- 卡片网格布局，自动适配列数
- 每张项目卡包含：颜色封面区域、标题、状态标签、最后更新时间
- 悬浮时卡片轻微上浮 + 阴影加深
- 空状态展示引导文案

### 4.3 工作流内部布局

- 阶段标题 + 内容上下排列
- 设定集使用三标签页切换（世界观 / 角色 / 关系）
- 大纲使用卡片列表展示各幕/段
- Beat 使用可折叠手风琴卡片
- 正文使用左右结构（章节列表 → 编辑器工作区）

## 五、核心组件设计

### 5.1 WorkflowStepper 工作流步骤条

- **水平步骤条**，串联 5 个阶段
- 每步显示阶段名称（中文）
- 状态视觉：
  - PENDING（灰色圆点）：未开始
  - IN_PROGRESS（蓝色旋转）：进行中
  - CONFIRMED（绿色对勾）：已完成
  - REJECTED（红色叉号）：已驳回
- 当前阶段高亮显示
- 点击已完成或当前阶段可导航切换

### 5.2 MarketAnalysisCard 卖点分析卡

- **步骤指示器**：三个子步骤（生成卖点 / 生成简介 / 确认完成）
- 每个卖点方案独立卡片展示：
  - 标题（加粗）
  - 核心卖点（重点文案）
  - 市场匹配度（数字 + 星级可视化）
  - 爆款参考（标签组）
  - 差异化分析（说明文字）
- 支持选中（高亮边框）

### 5.3 WorldBuilder 世界观构建器

- 可折叠面板（accordion）
- 四个维度独立面板：
  - 时代背景
  - 地理环境
  - 社会结构
  - 力量体系
- 查看模式：Markdown 渲染
- 编辑模式：文本域原地编辑
- 顶部"编辑"/"保存"按钮切换

### 5.4 CharacterCard 角色卡

- 三大角色分类：
  - 主角（teal 色标记）
  - 反派（red 色标记）
  - 重要配角（purple 色标记）
- 每角色显示四要素：名称、欲望、动机、结局
- 支持编辑模式，字段独立编辑

### 5.5 RelationGraph 关系图

- 两大区块：
  - 冲突关系
  - 情感纽带
- Markdown 渲染内容
- 支持编辑模式

### 5.6 BeatNarrativeCard 细纲叙事卡

- **折叠/展开模式**：
  - 折叠态：章节号 + 叙事摘要 + 字数/节奏/冲突/操作
  - 展开态：额外显示冲突描述 + 钩子因果链
- 章节号徽章（蓝色）
- 高潮标签（橙色）
- 待更新标签（红色）- Beat 被修改后标记
- 受影响标签（金色）- 关联调整影响
- 节奏标签：快(红) / 中(橙) / 慢(绿)
- 冲突强度：数字 1-5
- 预设快速操作："换一种写法"下拉菜单（节奏/冲突/悬念/重写/自定义）

### 5.7 ChapterActionBar 章节操作栏

**按章节状态动态显示不同按钮组**：

**PENDING 状态（无内容）**：
- [生成正文] 主按钮
- 模式选择下拉

**DRAFT 状态（生成中）**：
- [暂停] 按钮

**DRAFT 状态（已完成生成，有内容，未审核）**：
- [提交审核] 主按钮
- 重新生成区域：模式选择 + 反馈输入 + [重新生成]
- [确认完成]
- [标记争议]

**PENDING_REVIEW 状态**：
- [提交审核]
- [确认完成] / [标记争议]

**审核后（有审核结论）**：
- PASS：[确认完成]
- PASS_WITH_SUGGESTIONS：[采纳建议并重新审核] / [忽略并确认]
- NEEDS_REVISION：[采纳修改并重新审核] / [手动修改] / [上诉]
- BLOCKED：[手动修改] / [上诉]

### 5.8 ReviewPanel 审核面板

- 审核结论横幅（颜色对应结论：绿/黄/橙/红）
- 四维度评分卡片组：
  - 维度名称 + 得分 + 问题列表
  - 每个问题标注严重程度（LOW/MEDIUM/HIGH/CRITICAL）
  - 位置引用 + 规则说明 + 修改建议
- 上诉弹窗：
  - 原始结论 + 章节信息
  - 警告提示（仅一次机会）
  - 理由文本域
  - 提交/取消按钮

### 5.9 EditorWorkspace 编辑器工作区

- 章节标题（顶部）
- 章节正文（Markdown 渲染 + 可编辑）
- 目标字数进度条
- ChapterActionBar 操作栏
- ReviewPanel 审核面板（有审核结果时）

### 5.10 ChangeAnalysisPanel 变更分析面板

- 按严重程度分组显示：
  - HIGH 影响（红色）
  - MEDIUM 影响（橙色）
  - LOW 影响（蓝色）
- 每个受影响章节：章节号、原因、当前状态
- 操作：修复 / 跳过 / 推迟
- 空状态时显示"无影响"

## 六、动效与微交互

### 6.1 页面过渡

| 过渡 | 效果 | 时长 |
|------|------|------|
| 页面切换 | `page-fade`：淡入淡出 + mode="out-in" | 默认 |
| 阶段切换 | `phase-fade`：淡入淡出 + mode="out-in" | 默认 |

### 6.2 卡片交互

- 项目卡片悬浮：轻微上浮（translateY -2px）+ 阴影加深
- Beat 卡片选中：左侧边框高亮为品牌色 + 阴影
- Beat 卡片受影响：左侧金色边框 + 浅金色背景

### 6.3 加载状态

- 生成中：`<a-spin>` 旋转加载 + 文案提示
- 流式输出：正文逐字呈现
- 加载占位：骨架屏 / 空状态引导

### 6.4 反馈提示

- 保存成功：`message.success('修改已保存')`
- AI 不可用时：模态对话框 + 重试按钮

## 七、响应式与适配

- 基于 Ant Design Vue 的响应式栅格
- 桌面端优先（创作者主要使用环境）
- 内容区域最大宽度受限于页面容器
- 卡片网格自适应列数
- 标签页在小屏下保持可滑动

---

## 八、无障碍与可用性

- 所有可交互元素设置 `data-testid` 属性
- 操作按钮描述清晰：禁用状态有视觉反馈
- 错误状态提供重试入口
- 关键操作（切换结构、确认完本）有确认弹窗
- 空状态有引导性文案说明下一步操作
