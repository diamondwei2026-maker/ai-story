### Warning（存在隐患）

- **#2 Token 预计算未达 ADR 规格**: ADR-0007 要求通过 OpenRouter API token counting 端点使用 DeepSeek tokenizer 做预计算，当前实现 `estimateTokens()` 使用 4 chars/token 启发式估算。CONTEXT.md 已如实标注为"尚未实现"，但两者间存在精度差距——中文文本的 token 比通常在 1.5-2.5 chars/token 之间，4 chars/token 会系统性地低估中文 token 消耗约 40-60%，可能导致三层硬上限在实际超限后才触发裁剪 → 涉及：`src/step/CONTEXT.md`, ADR-0007

- **#3 ADR-0004 断点续传策略模糊归属**: ADR-0004 明确声明"断点续传 + 指数退避重试留待后续迭代"，但 CONTEXT.md 的"尚未实现"列表中未出现该项。该功能与已实现的 `retryChapterGeneration()` 可能有语义重叠——现有重试是否覆盖了 ADR-0004 描述的"≥60% 保留已生成内容续写"场景？建议确认后明确归属 → 涉及：ADR-0004, `src/step/CONTEXT.md`
