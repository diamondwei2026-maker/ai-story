# 蓝图逻辑审计报告 — Issue #22 完毕后

审计范围：DraftingView.vue / api/chapter.ts / api/project.ts / router/index.ts / PRD §2.1 / ADR-0005 Decision 2
审计日期：2026-06-04

---

### Blocker（必须先解决）

- **[B1] `confirmCompletion` / `reopenProject` API 端点未注册**：前端 `api/project.ts` 新增的 `confirmCompletion()` 调用 `POST /projects/:projectId/complete`，`reopenProject()` 调用 `POST /projects/:projectId/reopen`。服务端 `StepService.confirmCompletion` / `reopenProject` 方法已实现（#16），但 **ProjectController 中无对应路由**。当前前端测试通过是因为 vi.mock 拦截了 API 调用，生产环境中两个端点均返回 404。→ 涉及：ProjectController、api/project.ts

---

### Warning（存在隐患）

- **[W1] 完本横幅呈现位置与 WorkflowStepper 设计不一致**：WorkflowStepper 已内置 `showCompletionBanner` 计算属性 + `#completion-banner` 插槽（#16 实现），设计意图为横幅展示在 Stepper 下方、只读覆盖层上方。当前实现中 DraftingView 将 `<CompletionBanner>` 内嵌在章节列表末尾，WorkflowView 既未传递 `allChaptersCompleted` prop 也未填充 `#completion-banner` 插槽。Stepper 层的横幅插槽成为死代码。不影响功能但架构不统一。→ 涉及：WorkflowView.vue、WorkflowStepper.vue、DraftingView.vue

- **[W2] PHASE_TO_ROUTE 映射遗留注释未清理**：`WorkflowView.vue` 第 56 行 `PHASE_TO_ROUTE` 已包含 `DRAFTING: 'workflow.drafting'`，但 `router/index.ts` 中 `ProjectHubView.openProject` 的注释仍描述"BEATS/DRAFTING/COMPLETED 暂回退到 OUTLINE"。DraftingView 上线后 BEATS 已有视图、DRAFTING 本次上线，回退逻辑应同步确认是否已移除。→ 涉及：ProjectHubView.vue、WorkflowView.vue

- **[W3] DraftingView 不在 WorkflowStepper DRAFTING 阶段切换时重新 fetch**：DraftingView 仅在 `onMounted` 时调用 `fetchChapters()`。若用户在待生成状态下进入 DRAFTING 页面、去 BEATS 回退修改后切回，章节列表不会自动刷新。当前无实时同步机制（与 OutineView/SettingView 的 `usePhaseWorkflow` 不同）。→ 涉及：DraftingView.vue

---

### Info（优化建议）

- **[I1] DraftingView 字数统计使用字符数而非词数**：`wordCount()` 用 `replace(/\s/g, "").length` 统计中文字符，这与 CJK 语境下的"字"概念一致（中文每字即一词）。但函数命名为 `wordCount` 可能误导英文阅读者。建议后续统一为更精确的命名（如 `charCount`），或在所有 Phase 视图中统一使用同一种字数统计算法。→ 涉及：DraftingView.vue

- **[I2] 测试文件总数需更新**：CONTEXT.md 最后一行"前后端合计 846 条测试"已过期。本次新增 35 条 DraftingView 测试，实际前端测试数 ≥ 451（416 + 35）。下次更新 CONTEXT.md 时应重算全量测试数。→ 涉及：CONTEXT.md

- **[I3] `CompletionBanner` 组件仅用于 DraftingView 但仍为全局组件**：`CompletionBanner.vue` 位于 `components/` 目录，但仅被 DraftingView 引用。可考虑迁移到 `views/drafting/` 子目录或保持现状（后续 #23 流式编辑器可能需复用）。→ 涉及：CompletionBanner.vue
